Формат закодированного файла имеет следующую структуру:

1. Сигнатура формата (4 байта)
Первые 4 байта файла ― фиксированное «магическое число», позволяющее отличить этот формат от других файлов:
байт 'H' (0x48)
байт 'F' (0x46)
байт 'M' (0x4D)
байт 'N' (0x4E)

2. Исходная длина файла (4 байта, int)
Далее записывается целое число originalLength ― количество байт в исходном файле.
Это значение используется при декодировании, чтобы знать, сколько исходных байт нужно восстановить и где заканчиваются значащие биты (хвост последнего байта может быть добит нулями).

3. Количество различных символов (4 байта, int)
Поле distinct ― число различных байтов, встречающихся в исходном файле.
Если файл пустой, то originalLength = 0, distinct = 0, и на этом файл заканчивается.

4. Словарь (частоты символов)
Далее записывается информация о каждом встречающемся в файле байте:

для каждого из distinct символов идет пара полей:
1 байт ― значение символа (число 0..255, записывается как byte)
4 байта ― его частота в исходном файле (тип int)

То есть записи вида:
[символ_1][freq_1]
[символ_2][freq_2]
...
[символ_distinct][freq_distinct]

По этому словарю при декодировании заново строится дерево Хаффмана.
Коды символов явно не хранятся, они восстанавливаются из частот.

5. Закодированные данные (последовательность битов)

После словаря сразу идут данные, закодированные методом Хаффмана:
каждый символ исходного файла заменяется своим двоичным кодом

биты последовательно записываются в поток:
по 1 биту добавляются в текущий байт слева направо
когда набралось 8 бит, байт записывается в файл
в самом конце, если количество битов не кратно 8, последний байт дополняется нулями слева (эти добивающие нули при декодировании игнорируются — мы знаем точное originalLength).

В результате последняя часть файла — это непрерывная последовательность байтов.
